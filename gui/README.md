# SunPack 管理面板

独立的 Windows C++17 / Core UI 管理器，产物为 `SunPackGUI.exe`。
界面资源、Core UI、QuickJS 和 JSON 库静态编入 EXE，使用静态 CRT。
GUI 关闭即退出，Watch 的生命周期独立于 GUI。
界面参照 Windows 11 设置：左侧导航和细竖条选中提示，28 px 页面标题、
8 px 圆角卡片和低对比度边框；字体使用 Segoe UI Variable Text / 微软雅黑 UI。
支持跟随系统、浅色和深色外观。配置直接在列表中编辑，包含名称、说明、单位和
取值限制；有限选项使用原生下拉框，布尔值使用开关，字符串数组使用内嵌 TAG。
说明仅保留单位约定、边界条件等额外信息，不重复名称或控件已有提示；登录自启项显示为“开机启动”。
合并卡片的分隔线位于行边界，行内左右内容垂直居中，TAG 文字与删除区域保留独立间距。
侧栏和页面列表可滚动，操作按钮不参与横向压缩，空间不足的操作行换行。
配置开关和下拉立即保存；标量文本输入在失焦或 Enter 时保存。
文件大小与修改时间使用结构化上下限编辑器，留空表示无对应边界。
大小支持小数和 B/KiB/MiB/GiB/TiB 单位，以整数 `min_bytes` / `max_bytes` 保存，
两端包含；小数换算后的最小值向上取整、最大值向下取整，整数字节不经过浮点数。
修改时间可直接输入本地日期和分钟，也可打开主窗口拥有的 Core UI 无边框日历弹层，
保存为 UTC 分钟字符串 `start_utc` / `end_utc`，开始包含、结束不包含。
确认后沿原有字段保存链路一次写入整个过滤器，取消不改变范围。
弹层贴近日期字段，底部空间不足时向上展开，并限制在所在显示器工作区；
小工作区的内容可滚动，确认按钮保持可见。单实例弹层在外部点击、Esc、切换设置、
滚动或主窗口关闭时销毁。Tab / Shift+Tab 在日历、时间和按钮间移动，方向键选日，
PageUp / PageDown 翻月（Ctrl 翻年），Enter 确认。翻月及选日不写配置；
确认复用范围顺序及夏令时校验，并保留打开时区中的 UTC 分钟，未改边界维持原 UTC。
日历仅选中日使用蓝色填充，不单独将今天标蓝；同月选日复用网格，仅更新选择。
弹出/退出淡入淡出为 100/67 毫秒，复用有限动画调度，透明度未变化时不重复提交窗口属性。
上下限紧凑并排，空间不足时整个上限控件换行，不接受比较表达式或历史别名字段。
非法数字、日期、溢出或上下限冲突保留草稿并显示错误；外部更新复用字段冲突处理。

字符串数组及黑白名单在配置卡片内编辑：左上显示配置名，左下输入后按 Enter 添加，
右侧紧密排列 TAG，点叉号立即删除，超出固定区域时滚动查看。
未回车的输入在失焦、滚动、搜索及虚拟行回收时保留，切换左侧页面或配置分类后清除，
不会随关闭窗口或其他字段保存而写入配置。现有空字符串、空格、重复值及换行按原样保留。
TAG 使用单个原生绘制表面和缓存换行布局，只绘制可见条目，不为每项创建控件和脚本闭包。
密码列表仅显示密码和删除操作，点击密码原地输入，失焦、Enter 或滚轮自动保存退出。
密码页和任务页共用左下角的监控目录搜索和虚拟列表，仅用于选择范围。
“全部目录”只展示全局密码；选择某个目录只展示直接关联该目录的密码，不混入全局或父目录密码。
新增密码使用当前选中的目录范围并自动聚焦，空框提示可粘贴多行内容；
粘贴多行时一次原子保存多个密码，跳过空行，保留空格与 #。
新增和修改密码统一去重：相同密码的全部目录范围覆盖局部范围，
父目录覆盖子目录；不相互覆盖的目录合并到同一条密码记录的范围数组中。
同值密码在多个目录分别显示，文件中只保留一条记录。清空密码只移除当前目录的关联。
密码区域显示输入光标，保存保留卡片的显示位置。切换目录先提交当前编辑，保存使用开始编辑时的范围。
多目录密码在一个目录内编辑或删除时只修改该目录的关联，其他目录保持原值。
“监控目录管理”位于配置管理和密码管理之间，固定表头为监控目录、输出目录、深度检测。
目录路径原地编辑，失焦、Enter、滚轮保存；右侧文件夹图标打开系统目录选择器，
已有有效路径作为打开位置，空白或无效路径使用系统默认位置。深度检测使用开关，删除直接生效。
监控目录粘贴多行批量创建，新增记录的输出目录默认与自身相同；输出目录多行按显示顺序
从当前行开始依次填写，超出已有行的部分保留为空监控目录草稿，不丢弃输入。
批量编辑整批校验并原子写入，完全相同的目录设置去重，冲突保留草稿和错误。
主导航不再显示保存/放弃按钮。每次只提交当前字段或记录，不打包其他页面的半成品。
修改失败时保留输入并在对应位置提示；关闭窗口提交标量输入并等待已排队的写入，
尚未填写监控目录的非空草稿需先完成或取消，
失败时保留窗口显示错误，不弹出正常保存或放弃确认。
目录显示统一保留右侧路径，超长时在左侧加省略号，覆盖侧栏及任务目录。密码输入区域随窗口宽度伸缩，与删除按钮保留额外间距；
密码卡片不显示单列表头，数据行独立滚动。密码悬停显示输入框式底线，
深色模式为白线、浅色模式为黑线，文字保持主题前景色，显示与编辑时位置一致。
所有滚动容器为覆盖式滚动条及控件阴影预留 18 DIP 的右侧空间。
左栏加宽至 280 DIP，运行状态位于品牌右侧，标题下方常驻监控启停按钮，再排列四个页面入口。
品牌图标使用仓库的 `sunpack.png`，内嵌到 EXE 并限制为 40×40 DIP，无需外置图片文件。
监控目录列表位于导航入口下方，在任务页和密码页共用，搜索入口固定在滚动区外；
目录采用名称/路径两行显示。目录管理按钮及原二级编辑界面已经移除，
管理操作统一由独立页面的可编辑表格承担，表格按可见范围挂载行。
目录搜索下方的“全部目录”用于返回全部任务，具体目录在下方列表选择。
密码页将“添加密码”放在“密码列表”左侧，使用同样的按钮样式；
保存失败保留对应目录内的本行草稿，支持重新编辑或取消。
空白新增行失焦直接移除，不保存空记录。
剪贴板历史的长内容自动换行并撑高卡片，完整展示且保留原文，不溢出卡片边框。
每行可直接保存到左下角当前选中的目录，选择“全部目录”时保存为全局密码；
切换保存目标仍停留在历史页，保存复用密码去重与原子写入链路。密码和任务搜索均随输入更新，
任务状态选择也立即筛选，无手动筛选按钮。待处理的同类搜索只保留最新输入，无定时轮询。
界面语言跟随主配置 `cli.language`（zh/en），文件变化后即时更新。
系统标题栏同步深浅色，Windows 11 使用系统圆角；不支持这些 DWM 属性的
旧系统保留默认窗口边框。最大化、还原使用系统动画；主导航以 250 ms 轻微上移
配合 167 ms 淡入，选择标记在导航项之间移动。配置分类使用向上进入，密码列表与
剪贴板历史使用与切换方向一致的横向进入，目标数据与显示模式同时提交后开始过渡，
异步读取期间保留原视图；快速反向切换只应用最后选择的范围。数据变更成批绘制，切页不刷新文件。
所有过渡和开关尊重 Windows 动画开关，动画结束后停止请求帧。
首个数据快照完成并提交布局后才显示窗口，不展示初始化中的空页或临时状态。
滚轮和滚动条拖拽共用按显示刷新率提交视口的位置更新：一帧内合并输入，呈现完成后
再提交最新位置，鼠标消息不再同步绘制/等待呈现。滚轮使用连续衰减的附加速度，
遵守系统滚动行数及动画开关，反向输入立即改变方向；拖拽直接跟手，松手不加惯性。
滚动积分保留 QPC 的亚毫秒时间精度，避免高刷新率下整数毫秒采样造成位移步长不均。
虚拟列表保留视口附近 160 DIP 的行，接近缓存边界才补行；纯位移不重复测量已布局行。
静止拖拽、滚动结束或窗口隐藏时不请求空闲帧；搜索复位与程序定位取消当前惯性。
密码、剪贴板历史和监控目录每行独立成卡片，监控目录表头是固定的独立卡片。
两个管理页的搜索栏统一为 220 DIP，任务与密码页标题下不再重复显示左栏选中的目录。
GUI 删除监控目录时同步移除密码中该目录的直接范围关联；没有其他范围的记录删除，
共享记录保留其他范围，全局密码、独立子监控目录和剪贴板历史保留。沿用 GUI 保存
队列及现有文件锁，目录写入失败时恢复密码清理；成功回执清理该范围的待保存草稿。

## 构建与运行

需要 Visual Studio 2022 C++ Build Tools、Windows SDK、CMake 3.25+、Git。
使用仓库已有 `.venv`；Core UI 源码和许可证随仓库提供，其他依赖首次配置时获取。

```powershell
.\scripts\build_gui.ps1 -Arch x64
# ARM64 需要相应 MSVC ARM64 编译组件；在原生 ARM64 runner 上也执行测试。
.\scripts\build_gui.ps1 -Arch arm64
```

开发构建在 `.cache/gui-<架构>/Release/SunPackGUI.exe`。从源码运行的托盘
使用相同位置，并传入仓库数据目录及现有 Python CLI 入口。

```powershell
# 独立数据目录默认禁用 CLI 控制，防止测试数据误操作已安装的 Watch。
.\.cache\gui-x64\Release\SunPackGUI.exe --data-dir C:\SunPackGuiFixture
# 显式选择用于控制的 CLI；可重复 --cli-prefix 传入固定启动参数。
.\.cache\gui-x64\Release\SunPackGUI.exe --data-dir C:\SunPackGuiFixture --cli C:\SunPack\bin\sunpack.exe
```

安装版默认读取 `%ProgramData%\SunPack`，CLI 为同一安装目录的
`bin\sunpack.exe`。按数据目录单实例，再次打开会激活已有窗口。

## 数据与交互

- 任务：读取当前 `events.jsonl`，只根据已记录事件投影状态。全部结果连续滚动。
  卡片采用紧凑两行布局，目录取日志中文件路径的父目录，不依赖当前监控列表；只点击文件名打开目录，
  悬停时文件名变蓝。优先打开现有输出目录，原有监控目录回退规则保持不变。
  保留字节偏移及未完成末行；比较文件身份、固定前缀和已读末端锚点来识别
  原文件截断后重新增长。重置会清除旧投影，读取不涉及分卷、密码或格式分析。
- 目录：读取和编辑 `sunpack_watch_roots.txt`，保留注释，最后一条重复目录生效；
  默认输出相对该输入目录解析。目录连续滚动，无“更多”按钮。
- 密码：严格校验 `builtin_passwords.json`；保留原始密码文本和剪贴板历史。
  左栏选择全部目录时仅展示全局密码，选择具体目录时仅展示关联该目录的密码。
  同值密码合并为一条多目录记录，全局范围覆盖局部范围。
  默认添加单个密码，输入框直接粘贴多行批量添加，忽略空行和完全重复记录，保留空格与 #；
  同一密码文件的修改在一个运行时互斥锁中校验并原子保存，不会只写入部分密码记录。
  编辑或删除多目录密码只修改当前目录的关联。剪贴板历史直接保存到当前选择范围。
- 配置：显示主配置已有字段；使用内嵌的中英文说明目录，将筛选器及模块数组展开为
  易懂的独立设置。中英文名称覆盖当前 `sunpack_advanced_config.json` 的全部可编辑值，
  仅保留必要的简短说明，按宽度自动换行，不重复标题或单纯的数值类型限制。
  搜索匹配当前语言的名称、说明、下拉选项、范围提示及显示值，也覆盖主题和开机自启，
  不再使用内部字段名或模块名匹配。
  支持移入普通配置的高级值。按完整路径和模块名匹配，不按字段尾名兼容旧配置。
  动态识别所有字符串数组，未知的其他类型只读并保留在文件中，不要求用户在表单填写 JSON。
  保存时在锁内回读，只替换指定字段的原始 JSON token，因此未知字段、格式、
  数组结构和超过 JavaScript/uint64 精度的大整数均不被重新序列化损坏。
  外部冲突在对应字段显示并保留输入；保存期间继续输入也不会丢失新值。
  目录和密码单元格按首次点击的文字位置进入编辑，长目录按省略显示的尾部定位；
  相同内容的数据回写保留光标及选区。
- 标量自动保存与集合、记录的显式保存复用同一个工作线程和 `save_changes` 的校验、文件锁及原子替换。
  同时只有一次提交在进行，同一目标的待写更改合并为最后一次完成编辑的值。
  成功回执只推进该次写入的比较基准；密码合并仍保留最新剪贴板历史和无关记录，
  监控目录仍比较原输出和深度检测值以发现外部修改。没有保存定时器或空闲轮询。
- 文件编辑使用同目录临时文件和原子替换。密码、目录分别复用运行时的
  `Local\SunPack.EditableFile-<XXH64>`、`Local\SunPackWatchRoots-<XXH64>`。
  Windows 路径大小写通过 NT Unicode 映射，XXH64 复用已有 LZ4 源码。
- 使用 `ReadDirectoryChangesW` 和注册表变化通知；不扫描压缩文件或监控根目录。
  日志位置随实际主配置的 `watch.state_dir` 变化重新绑定。共享冲突等临时读取错误
  保留上一份有效数据，仅调度最多三次 5/20/80 ms 的单次重试，之后等待新通知。
  目录不存在时观察现有祖先，创建后重新绑定。
- Watch 启停、自启开关仅启动现有 CLI 命令。配置和监控目录保存后由后台文件观察器
  自动加载；GUI 不提供重复的手动重载操作。自启显示值直接读取
  `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\SunPackWatchService`。
  CLI 输出以自动删除的临时句柄捕获，不保存额外历史，不启动 GUI 的 IPC 服务。
  成功保存与 CLI 退出码 0 不弹出提示；失败在当前操作区域显示。
  运行标志读取 Windows SCM 中 `SunPackWatchBroker` 的状态，仅 `SERVICE_RUNNING`
  显示运行中；普通 runtime 命令和残留状态文件不影响该标志。
  复用注册表观察线程，通过 `NotifyServiceStatusChangeW` 订阅状态变化，使用
  `WaitForMultipleObjectsEx(INFINITE, TRUE)` 接收 APC。回调只记录结果并释放 SCM 返回的
  名称缓冲区，状态读取和重新订阅由等待线程完成，避免回调中的 SCM/RPC 重入。
  查询后订阅其他状态，覆盖查询和订阅之间的变化；服务未安装或正在卸载时，改为
  订阅 SCM 服务创建/删除事件，安装后自动恢复。访问失败显示状态未知，窗口激活或
  CLI 命令完成可触发一次重试；通知落后时立即重连一次，不安排定时重试。
  不引入应用层 IPC、轮询、新线程或后台服务。关闭时在观察线程上取消订阅并排空
  已入队 APC，之后释放通知缓冲区；线程结束后 GUI 再释放其余事件句柄。
  该标志表示监控代理运行：最后一个 Watch 客户端退出后 broker 约一秒后停止，
  一次性 Watch 也可能短暂启动 broker，因此不等同于长期监控任务已启用。
  APC 和取消规则参照 [Microsoft 的服务状态通知文档](https://learn.microsoft.com/en-us/windows/win32/api/winsvc/nf-winsvc-notifyservicestatuschangew)。
  状态未变化时不更新界面。主界面不显示数据目录或日志路径页脚。
  资源管理器入口定位文件，避免执行伪装成 `.exe` 的压缩包。

配置按所属对象合并为卡片；筛选器、格式模块和验证方法各自独立成组。
开关直接使用模块名称，其他参数在同一块内编辑保存；搜索和虚拟列表不会拆开模块。
CLI 操作保留页面与按钮外观，进行中的重复点击被忽略，完成后恢复接收命令。

Core UI 固定提交存在动态嵌套 `v-if` 子树卸载后的悬空观察器问题，已由 ASan 复现。
本界面保留视图容器并使用 `v-show`；配置块使用恒真条件作用域绑定内层列表，
随所属分组一起释放，不通过它切换显示。原生下拉框挂载幂等，防止父子生命周期
重复通知造成重复控件。配置开关复用同一原生控件，动画期间只重绘；独立的开关草稿通道
避免每次点击重新绑定其他配置输入，自动保存回执同步基准与控件状态。
Core UI 的完整源代码在 `third_party/core-ui`，连同原始许可证一起跟踪；上游提交和
本地修改见 `third_party/core-ui/SUNPACK_CHANGES.md`，构建直接使用此目录。
原实现使用粗粒度时钟及 16 ms 窗口计时器，
本机曾连续测得 31 ms 帧间隔；现在使用高精度时钟，在已有渲染线程开启活动动画帧的
垂直同步，并在呈现后请求下一帧，最终帧不再请求后续帧。不增加线程、空闲轮询或
常驻高精度系统计时器。开关分别处理 167 ms 滑块位移、83 ms 颜色变化与悬停/按压
形变，快速反向切换从当前视觉位置续接，键盘空格/回车同样可操作。
下拉框沿展开方向做 167 ms 短距离滑入和 83 ms 淡入，关闭时保留 83 ms 退出画面，
但立即停止接收列表输入。反向操作从当前位置续接，尊重系统动画设置；展开与关闭均不
改变父容器布局。滚轮直接复用 ScrollView 的坐标平移，移除了窗口事件分发中重复且没有
文本测量上下文的布局，避免中文按钮宽度被估算值覆盖；滚动条拖动保持同样的平移路径。
`src/motion.cpp` 是管理器使用固定 Core UI 动画接口的集中适配，位移只影响绘制，
不逐帧重排布局。时间、曲线、开关形变依据
[WinUI 开关模板](https://github.com/microsoft/microsoft-ui-xaml/blob/main/controls/dev/CommonStyles/ToggleSwitch_themeresources.xaml)、
[Windows 动效](https://learn.microsoft.com/en-us/windows/apps/design/motion/)和
[页面过渡](https://learn.microsoft.com/en-us/windows/apps/design/motion/page-transitions)调整。
顶层命令信号不可见且采用绝对定位，不参与页面布局；
原生句柄在卸载时释放。任务、配置块、密码/剪贴板历史及监控目录统一使用
`VirtualList`：仅挂载视口附近的行，滚动后卸载离开的行；正在输入的编辑器保留至失焦。
列表缓存行高并用树状数组查找位置和修正估算高度，滚轮和拖拽的纯位移不重新布局；
补行、缩放及内容变化只测量已挂载的行。筛选仍针对全部数据，不新增后台轮询。
列表数据更新按条目键复用已测行高，避免自动保存或文件通知替换数组时重置估算高度，
造成配置、任务、密码及目录列表跳动；实际内容高度变化仍由已挂载行的布局测量更新。
配置分类、滚动复位和进入动画在同一次视觉事务内提交，避免新分类先以不透明状态
显示一帧。补行只在所属滚动区内收敛布局，保留已有页面布局请求；横纵容器复用同轮
测量，虚拟行高度稳定后停止重复排列。没有 `onResize` 的页面不再额外重排一次。
虚拟模板函数按参数签名和源码复用，页面内最多 512 项、128 KiB 源码，销毁页面时释放；
不缓存行对象或其闭包参数。日期弹层用同一呈现时钟进行 167 ms 淡入、83 ms 淡出，
尊重系统动画设置，确认通过原有保存链路后退出，动画结束消息由主窗口释放弹层。
选择按钮用焦点底线，日历日期使用选中填充，不叠加焦点外框。
窗口使用
prepare/show-immediate 路径，使用系统标题栏，不创建托盘或 Toast。

## 安装升级

安装器先停止 CLI、Watch、GUI 及 broker，再检查已安装版本。
低于 1.2.0 或无法识别版本时，整体删除程序目录、`%ProgramData%\SunPack` 和配置
指定的自定义 Watch 状态目录，再安装全新默认数据。密码、配置、监控目录、日志和
状态均不保留，也不执行格式转换。更换安装位置时同样删除注册的旧程序目录。
1.2.0 及以上版本重装保留数据目录；程序文件和高级默认配置始终替换。
新安装从安装包复制普通配置与密码 JSON，修复数据目录权限，并创建本地化监控目录文件。
GUI 和运行时只处理当前格式，没有数据升级命令或旧格式解析器。

## 验证

`build_gui.ps1` 运行两个原生粗粒度测试及 Python 跨语言契约测试。
`tests/gui/README.md` 说明每个测试的独立覆盖和成本。
可设置 `SUNPACK_GUI_SCREENSHOTS` 为一个新目录来保存三个页面、浅色主题及
最小窗口编辑状态的测试截图。
任务卡片时间统一换算为电脑本地时间，以 `YYYY-MM-DD HH:mm:ss` 显示。点击文件名
打开日志记录的首个仍存在的输出目录；没有可用输出目录时打开所属监控目录。
已不在监控列表的历史任务回退到原文件的父目录。目录在点击时检查，无额外轮询。
任务模型只保存状态、时间和输出路径，不再保留完整日志详情或清理记录。
布局测量复用有容量上限的文本宽度缓存，
缩放不再重复创建相同文字的 DirectWrite 布局；缓存不持有文本布局或新增后台任务。
内存诊断可配置 `-DSUNPACK_GUI_ASAN=ON`，不要发布 ASan 产物。

工作集约 53 MiB、私有内存约 56 MiB，3 秒空闲 CPU 时间增量为 0，关闭退出码 0。
这些数字包含系统图形驱动开销，随机器、DPI、目录及任务数量变化。

x64 Release、原生界面/文件契约、跨语言锁与剪贴板协作、ASan 界面测试已运行。

ARM64 GUI 的实际构建与运行尚待双架构发布 CI 验证；旧 CPU、Windows 10 和
