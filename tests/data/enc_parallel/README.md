These fixed ENC v4 payloads were generated with the official Paranoia Works
SSE File Encryptor 17.4.4 Java engine and `tests/helpers/EncV4Fixtures.java`.
The reference implementation was downloaded from
https://paranoiaworks.mobi/download/files/SSEFilePC.zip on 2026-10-08.

`algorithm_0.enc` through `algorithm_9.enc` cover AES, RC6, Serpent,
Blowfish-256, Twofish, GOST, Blowfish-448, Threefish, SHACAL and the C4 cascade.
Each decrypts to the same 2 MiB `large.expected`, generated by
`java.util.Random(42).nextBytes`. The password is `sunpack-test`, the salt is
32 bytes of `0x73`, and the KDF parameter byte is zero.

These vectors remain available for native worker and carrier-range compatibility
regressions. Tests should copy a vector before corrupting its MAC or wrapping it
in a carrier; the committed data must stay unchanged.

To regenerate all ten vectors with an official reference JAR (Java 17+):

```sh
javac -cp /path/to/ssefenc.jar -d /tmp/enc-fixtures tests/helpers/EncV4Fixtures.java
java -cp /tmp/enc-fixtures:/path/to/ssefenc.jar EncV4Fixtures tests/data/enc_parallel --large-only 2
```

Use `;` instead of `:` in the Java classpath on Windows. Keep these assets at
2 MiB so they can exercise streaming across unaligned ranges. The Java helper
is only for deliberate fixture regeneration.
