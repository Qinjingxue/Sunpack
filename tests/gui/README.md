已废弃的 Watch/调度/普通压缩流预算字段不再被识别，未知字符串数组保持只读，
并检查 worker 的实际数值边界。

会失去该覆盖。新增检查都在原进程内完成，不增加文件、等待或逐字段测试。

所有测试使用隔离文件，不控制正式 Watch、自启或密码文件。没有性能阈值测试。
页面动效复用同一窗口，在中间位移状态重复入场、共享目录列表的页面之间切换、快速
离开并返回；观察实际动画帧，检查页面与侧栏始终不透明、子视图没有独立动效、共用
目录列表保持原位、配置侧栏与主页面一起入场，最终布局与导航位置稳定且有限位移结束。

删除这些检查会失去该覆盖。复用既有窗口、分类与导航序列，仅增加少量内存属性检查和
一次共享侧栏切换，不新增进程、固定等待或性能阈值，保留系统关闭动画的分支。

无法发现集合底部悬浮提示，删除此检查会失去独立覆盖；仅增加一次鼠标移动。

无法发现残影、裁剪漏画或缓存导致的文字吸附变化；删除后没有独立像素覆盖。
