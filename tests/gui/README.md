# GUI 测试取舍

所有测试使用隔离文件，不控制正式 Watch、自启或密码文件。没有性能阈值测试。

同一界面场景检查监控操作位于导航入口上方、目录列表位于入口下方且处于同一左栏，
并在密码和配置页面执行原有启停场景，验证操作常驻。最小窗口保留至少两行带上下留白的目录卡片，
添加按钮不随目录滚动而移动。文件契约不能发现布局或页面可见性回归；复用原有点击和截图，无额外进程。

界面集成场景复用现有密码、目录数据，检查列表中的删除按钮与编辑按钮同排对齐，
删除准确落盘、保留剪贴板历史和其他编辑内容、清除已删除目录的选择且保留实际文件夹。
文件契约测试不能发现列表事件绑错记录或删除后界面状态残留；只增加几次按钮点击和小文件写入。

| 测试 | 独立发现的功能故障 | 删除后的缺口 | 成本与价值 |

| `interface.cpp` 原生界面集成 | 真实文本/开关/下拉框行内保存；DWM 动画开关与非空切页过渡；中英文即时切换；保存期间继续输入及外部同字段修改时保留草稿；850×560 批量密码保存；安静的 CLI 成功反馈；观察器恢复、日志重绑定及退出 | 数据测试不能发现绑定失效、保存确认覆盖新输入、被裁剪的按钮、原生控件语言未更新或窗口生命周期错误 | 本机 Release 约 10 秒；复用同一窗口，等待实际事件，没有固定等待或性能阈值 |

| Python 安装版启动 | 托盘定位独立管理器、复用降权启动并释放原生子进程句柄 | 托盘测试仅替换启动函数，无法发现实际路径和生命周期错误 | 纯单元测试，几毫秒 |

`tests/unit/test_windows_tray.py` 原有文件打开测试被菜单/左键统一打开管理面板
的测试替代，旧实现与对应旧断言一并删除。

文件契约粗场景还覆盖安装升级的五项废弃字段清理、空节移除、重复运行和原文保真；
其他 JSON 编辑测试不涉及字段删除的逗号边界，不能替代此覆盖，成本为几次小文件操作。
界面场景将全部高级配置移入普通配置，在最小窗口检查分类和设置卡片与滚动条的间距；
文本/开关事件测试无法发现覆盖式滚动条遮挡，复用窗口仅增加一次文件更新和截图。

同一界面场景还检查白名单的开关和规则同属一张卡片，以及启停、自启命令后
页面位置、可见性和不透明度保持稳定。
运行标志改为 SCM 后，旧进程/状态文件测试及临时安装副本启动器一并删除。
文件契约目标中的 `service_monitor.cpp` 仅替换测试 EXE 的五个 SCM 导入，仍执行生产
`ServiceMonitor` 和真实 Windows APC/alertable wait。一个粗场景覆盖服务缺失、
其他服务创建、启动/停止及过渡状态、查询与订阅之间变化、RPC 内提前投递 APC、
一次性订阅重新注册、通知落后重连、卸载重装、访问失败，以及有 APC 排队时销毁。
其余文件测试不能发现 SCM/APC 生命周期错误，删除后这些故障无覆盖；该场景仅需
几次内存模拟和内核事件投递，不创建或启停服务、不启动额外进程，无固定等待。
界面场景读取真实 SCM 状态并验证观察线程可随窗口关闭；不修改正式 broker。

界面场景另外用 73 个目录和 30 条剪贴板历史检查最小窗口的可见行数、滚动后添加按钮
位置/文本宽度、目录选择编辑以及历史另存为手动密码时的原文保留。其他文件或单条数据
测试不能发现滚动触发的按钮截断和低密度布局退化；复用窗口与现有列表上限，仅增加
两次小文件更新和少量滚动事件，不设性能阈值。

文件契约粗场景继续验证底层保存器的同字段冲突、大整数原文保留、最新剪贴板历史
合并，以及 Windows 拒绝替换文件后的错误处理。界面场景改为验证自动保存：开关及
下拉立即写入、文本失焦提交、在真实文件锁阻塞写入时继续输入、外部冲突保留输入、
批量添加直接落盘及关闭窗口提交当前输入。不再模拟手动保存/放弃按钮。
同一粗场景还在文件锁下连续编辑同一密码，验证回执推进原始记录且不关闭编辑器，
验证已有目录的输出和深度开关自动保存、删除立即生效，以及无效数值不阻塞其他字段。
关闭遇到无效输入时窗口必须保留，修正后才能完成关闭；不另外创建窗口或独立控件测试。
这些事件与回执覆盖无法由直接调用文件保存函数替代，复用同一窗口和文件，仅增加
少量消息派发与临时文件操作，不添加轮询或固定等待。

同一粗场景还覆盖统一密码列表与作用范围、真实输入触发的密码/任务搜索及清空搜索，
批量目录的整批校验、去重和跨页自动保存。界面检查中英文操作按钮在最小窗口、长列表
和实际滚动后的文本宽度，并确认开关产生连续、有限且无需布局的动画帧，开关草稿不触发
其他配置输入的绑定。旧单条编辑和静态截图不能发现这些事件、批次及裁剪故障；
复用文件/界面粗场景和内置追踪，仅增加一次短动画和少量输入/滚动事件，无性能阈值。

动效仍复用同一窗口场景：快速反向导航后检查选择标记最终位置，实际悬停、按压和
键盘切换后等待有限动画结束，并通过追踪确认停止请求帧、开关动画不触发布局。
仅保存开关值的测试不能发现视觉位置错误、漏发后续帧或动画结束后继续唤醒；
这些事件覆盖值得增加的几次短交互，不添加独立控件测试或帧率阈值。
可设置 `SUNPACK_GUI_MOTION_DIAGNOSTICS=1` 输出动画帧间隔中位数和最大值，
用于人工定位调度问题。截图等待已有动画到达最终状态，无固定等待。

滚轮回归直接检查事件后的按钮宽度与文本，不再先强制布局：此前检查前的布局会修复
测量上下文丢失造成的截断，从而掩盖真实故障。另检查滚动条拖动、密码两行内容的
编辑按钮居中，以及下拉框上下展开、Escape 关闭、退出中重新展开和实际选项点击。
等待动画结束并确认停止请求帧；这些故障不在静态尺寸和直接设置下拉值的覆盖中，
复用同一粗场景，增加几次短交互，无独立性能阈值。

滚动条事件回归保留512 个任务的虚拟列表，切到配置页后交替滚轮与真实鼠标拖动，检查可见
滚动位置确实变化、隐藏任务页不动，以及释放后不再拖动。按下前不强制布局。
原来的拖动检查只看按钮宽度，即使点击被隐藏页面截获也会通过；这个场景覆盖输入路由
和捕获释放，仅增加两次切页与四次短拖动，不启动新窗口或添加固定等待。

任务投影场景另外覆盖 ISO 时区偏移、秒数时间戳、本地时间显示和缺失时间，
并确认不再投影原始日志详情。原来的状态/排序检查不能发现直接显示 ISO 原文或时区
换算错误，成本仅为几次内存投影。界面场景用512 个任务的虚拟列表连续调整窗口宽度，
检查按钮文字、卡片紧凑高度与日志文件父目录（独立于当前监控根目录），以及卡片及目录文字点击无跳转、
只有文件名悬停变蓝并点击发送一次打开目录命令，不出现详情面板；
测试在派发前消费命令，避免打开真实资源管理器窗口。原来单任务截图无法发现
大量卡片布局开销或点击绑定错误。复用同一窗口，不设机器相关耗时阈值，
输出布局耗时供人工比较，不新增 benchmark 测试。
任务投影粗场景还覆盖多个输出目录、点击前输出被删除、源归档已删除、嵌套监控根、
等待密码时无输出及监控项已移除时的回退；仅点击命令测试无法发现目录选择错误，
成本是几个临时目录，无运行时或资源管理器进程。

`tests/integration/test_installer_password_permissions.py` 的升级测试编译并运行生产
Pascal 迁移过程的隔离安装器，调用真实原生升级入口，覆盖有效高级参数保留、
旧密码及剪贴板历史转换、已有 JSON 优先、旧文本/备份清理和失败时保留源文件。
原生单测和 ACL 测试无法发现安装器的调用参数或清理顺序错误；只编译一个小安装器，
通常约 1 秒，使用临时数据目录，不执行真实系统安装。

连续列表复用原有界面场景，以 512 个任务、全部高级配置块、73 个目录、240 多个多范围密码、
320 条剪贴板历史验证往返顶部与末尾、条目可达且已挂载行少于 40。它能发现取消分页后
条目被截断、虚拟高度错误与旧行未回收等小列表无法暴露的问题，不另设逐项用例或时间阈值。

配置搜索通过真实输入框执行全选、替换与清空，并等待搜索命令和布局完成。
不直接改 `configQuery` 后假设行控件同步存在；虚拟列表会卸载视口外的行。
同一自动保存/错误草稿/关闭窗口场景继续验证搜索切换后的编辑行为，无额外用例或固定等待。
虚拟列表滚动检查复用窗口的文本测量入口，避免绕过程序滚动路径后，
用估算文字尺寸影响行高与末尾位置；保留原有末尾可达、行数上限与回收断言。

同一长目录场景在选择目录后检查文字与卡片上下边缘保留内边距，覆盖虚拟列表忽略
行最小高度造成的文字溢出；原有条目可达和按钮宽度检查无法发现此问题。
复用已选目录与截图，只增加一次布局树读取，无独立用例或额外窗口。

下拉框场景还检查展开后在菜单内滚轮不会滚动配置页或改变选择，菜单外滚轮则滚动
配置页并在原屏幕位置播放退出动画，退出期间菜单不能跟随锚点移动。静态层级和
Escape 关闭检查无法发现这类滚轮事件路由故障；复用主题下拉框，仅增加两次短交互。

中英文切换场景检查四个原生搜索框的框内提示同步更新，继续复用真实输入检查实时搜索。
仅检查语言状态和字段说明不能发现 placeholder 绑定遗漏；增加八次原生属性读取，无额外窗口。
