# GUI 五项性能优化实测（2026-10-21）

五项优化已实现。三轮交替对照中，配置页滚动的进程 CPU 时间下降约 22%，
GPU 引擎忙碌时间下降约 87%；切页 CPU 周期下降约 19%，呈现间隔更均匀。
动画时长、缓动曲线、滚动行为及绘制质量保持原值，没有增加帧率上限或空闲轮询。

## 实现

1. **脏区绘制与呈现**：精确比较前后 DisplayList，合并旧、新绘制范围，
   裁剪重放并向 `Present1` 传递脏矩形。补绘交替双缓冲上一帧的变化，避免残影。
   文字和任意 SVG 用其有效裁剪范围保守估算；尺寸、字体环境变化、截图、预备帧、
   背景采样和 SVG 文字运行保留完整重绘路径。
2. **绘制资源复用**：DirectWrite 绘制布局使用 LRU，最多 512 项、65536 个
   UTF-16 单元，超过 4096 单元的单条文本正常绘制但不入缓存。键包含文字、字体、
   布局宽高、对齐和换行，不包含位置与颜色。SVG 文档最多 64 项、128 KiB XML，
   大文档绕过缓存；画刷最多 128 个加一个临时画刷，图层池最多 8 层。
   字体/回退/绘制模式随帧提交，相关环境或目标变化时清理缓存。
3. **动画内容复用**：稳定透明动画子树复用至多 64 段有序几何命令，
   仍在实时变换下绘制文字。完整缓存文字会改变小数位移时 DirectWrite 的像素吸附，
   像素对照发现该问题后，最终实现仅保留几何段，没有文字位图缩放。
   动画结束、内容或渲染目标变化即释放。
4. **鼠标事件与呈现节奏**：相同悬停状态不重复绘制；用弱引用登记打开的下拉框，
   滚动悬停仅处理旧、新命中祖先，不再逐次扫描全树。必要重绘进入既有消息调度器。
   鼠标离开仅清理悬停，不模拟拖拽移动。DXGI 驱动队列深度设为 1，避免较便宜的
   缓存帧在默认三帧队列中产生不均匀的完成间隔；保留 `Present(1)` 和既有动画调度。
5. **虚拟行布局复用**：仅视口补行时复用仍挂载、同宽、同高度的行，直接平移子树。
   新行正常测量，数据更新及普通根布局、字体、尺寸变化仍重新测量。缓存仅含挂载行，
   以弱引用验证身份，不持有已回收控件；overscan 保持原值。

## 测量方法

- 基线为 `dev` 的 `514e93202ce5197b4070693388897e8eeff812a7`。
  从该提交导出隔离源码，将最终同一份 `performance.cpp` 放入基线构建；
  前后都用 MSVC x64 Release、同一套依赖源和编译选项。
- 本机：i9-13980HX、RTX 4090 Laptop、2560×1600 / 240 Hz；窗口设为 1120×720 DIP。
- 每个版本运行三次，顺序为 before → after，重复三组；测量期间不进行编译或其他测试。
- 参数一致：`--tasks 5000 --passwords 3000 --history 3000 --roots 250 --rounds 5`。
  每轮包含 19 次 `page_switch_settled` 采样；滚动按录制帧事件输入，最多 1500 次滚轮。
- 表格默认取“三轮各自均值的中位数”；P95 表格取三轮各自 P95 的中位数。
  单次进程 CPU 时间有 Windows 记账粒度误差，故同时记录 CPU 周期。
- GPU 使用进程 PDH `GPU Engine(*)\Running Time` 的增量，单位是所有相关引擎
  忙碌时间之和。它不是 GPU 百分比、功耗或 `Present` 等待时长；引擎可以重叠执行。
- 呈现间隔为 QPC 记录的 `Present` 完成间隔，不能等同于实际扫描输出或输入到光子的延迟。

三轮分项结果、范围和缓存峰值见 [JSON 汇总](optimization-2026-10-21.json)。
本工作区六份完整原始记录为 `.cache/gui-five-result-{before,after}-{1,2,3}.json`。
早期尝试记录没有混入最终统计。

| 场景 / 指标 | 优化前 | 优化后 | 变化 |
| --- | ---: | ---: | ---: |
| 配置页滚动 CPU 时间 / 整段 | 8953.1 ms | 6984.4 ms | −22.0% |
| 配置页滚动 CPU 周期 / 整段 | 21547.4 M | 16874.2 M | −21.7% |
| 配置页滚动 GPU 忙碌时间 / 整段 | 431.0 ms | 57.7 ms | −86.6% |
| 配置页滚动 CPU 时间 / 呈现帧 | 6.27 ms | 5.08 ms | −19.0% |
| 配置页滚动 GPU 忙碌时间 / 呈现帧 | 0.302 ms | 0.0427 ms | −85.9% |
| 配置页虚拟行布局 / 次 | 1.074 ms | 0.126 ms | −88.3% |
| 配置页冷遍历操作 / 次 | 2.045 ms | 1.246 ms | −39.1% |
| 配置页热遍历操作 / 次 | 1.558 ms | 1.052 ms | −32.5% |
| 切页 CPU 周期 / 次 | 336.1 M | 273.0 M | −18.8% |
| 切页 CPU 时间 / 次 | 157.9 ms | 114.3 ms | −27.6% |
| 切页 CPU 周期 / 呈现帧 | 7.69 M | 4.77 M | −38.1% |
| 同目标 1000 次鼠标移动 CPU 周期 | 851.1 M | 64.7 M | −92.4% |

滚动阶段三轮的平均脏区面积约为整窗的 10.0%–10.6%，其 P95 约为 54.5%。
这个均值包含滚动到尾部后的无变化帧，不能解读成每个正在移动的画面都只重画 10%。
录制和呈现数量不同，故同时给出整段及每呈现帧的成本。
以上是五项合并后的收益，没有用单次总收益推断各项独立贡献。

## 流畅度与取舍

| 呈现场景 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 切页平均间隔 | 5.62 ms | 4.24 ms |
| 切页间隔 P95 | 13.62 ms | 4.18 ms |
| 切页间隔最大值（三轮中最差） | 18.36 ms | 15.99 ms |
| 滚动平均间隔 | 4.48 ms | 4.53 ms |
| 滚动间隔 P95 | 4.82 ms | 4.91 ms |
| 滚动间隔最大值（三轮中最差） | 17.95 ms | 14.31 ms |

滚动间隔的三轮范围相互重叠：均值 before 为 4.465–4.558 ms，after 为
4.467–4.534 ms；没有以帧率限制换取开销降低。切页 P95 稳定在 4.176–4.183 ms，
更接近 240 Hz 的 4.167 ms 周期。切页的呈现帧数从每轮 821–863 增加至 1082–1093。

切页 GPU 总忙碌时间中位数为 16.50 → 16.74 ms，基本持平；按呈现帧归一化则为
0.382 → 0.292 ms。这里不能宣称切页 GPU 总量明显下降。
GPU 时间受频率、调度和后台负载影响，尤其短场景三轮波动较大。

不是每个操作都更快：普通尺寸调整的同步操作均值为 1.51 → 1.85 ms，配置页尺寸
调整为 3.00 → 3.22 ms；完整失效仍有新绘制分析与资源整理成本。下拉动画 CPU 周期
约增加 2.9%，没有测得稳定收益。后续若继续优化，应针对完整失效路径及补行的 JS
模板挂载，避免再次重测全部已布局行。

整轮后的进程工作集中位数为 119.1 → 130.6 MiB（约 +11.5 MiB），包括缓存与驱动
驻留，未精确归因到各项分配。最终采样的峰值为 512 个文字布局、9386 个 UTF-16
单元、38 个画刷、4 个 SVG 文档、21 个保留几何段，均在上限内。缓存以渲染目标/
窗口/动画为生命周期边界；这次短程测试不等同于长期泄漏证明。

前后三轮空闲 5 秒都没有绘制帧、控件动画帧或属性动画帧，未引入空闲轮询。

## 正确性验证

- 最终 Release CTest：2/2 通过（10.37 秒）。
- 最终不带参数的完整原生界面回归通过，覆盖滚动拖拽、回收后编辑、保存冲突、
  中英文切换、观察器文件替换及弹层生命周期。
- 最终 AddressSanitizer 原生验收通过，未报告内存访问错误。
- Python GUI 集成：5/5 通过。
- 新增一个粗粒度像素对照场景：21 帧、两个短生命周期窗口，对比优化绘制与新缓存
  完整重画；仅容许单通道 1 级舍入差。覆盖双缓冲、小数位移、透明度、动画中内容
  改变、SVG、换行/省略/长文本、画刷上限、尺寸与渲染目标重建及字体回退变化。
- 同目标连续鼠标事件不提交同步帧，也不留下重绘区域；拖拽和反向滚动沿用原测试。

测试的独立覆盖和成本取舍见 [GUI 测试说明](../../tests/gui/README.md)。
工作区日志为 `.cache/gui-five-{ctest-final,full-ui-final,asan-final,python-final}.log`。

