These small fixed ENC v4 vectors were generated with the official Paranoia
Works SSE File Encryptor 17.4.4 Java engine by `tests/helpers/EncV4Fixtures.java`.
The matching upstream source revision is
`0e14eb51108114f9015f9ef2aa677fcb7ba30d28` in
https://gitlab.com/paranoia-works/paranoia-encryption-tools-for-pc .

Password: `sunpack-test`; Unicode vector: `contraseña中文😀`.
`algorithm_0.mov` through `algorithm_9.mov` cover every on-wire cipher ID,
including decrypt-only Blowfish-256 and GOST, and the C4 cascade. All decrypt
byte-for-byte to `expected.zip`. `params_01` doubles time, `params_10` doubles
memory. The Unicode vector preserves the official Java UTF-16 conversion.

`recovery.enc` was generated by the official CLI with `enc -p sunpack-test -a
aes -z deflate --recovery 10`. It decrypts to `recovery.zip`. Recovery data is
authenticated but never decrypted or repaired. These files contain only
test text and have no production passwords or private data.

`bad_mac.enc` changes the final authentication byte. `nested.enc` contains a ZIP
with `movie.bin`, a disguised Twofish ENC containing `expected.zip`; it checks
that ordinary recursive discovery handles both encryption layers.
