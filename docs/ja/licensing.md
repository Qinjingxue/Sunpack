# ライセンスと配布

[English](../licensing.md) | [繁體中文](../zh-TW/licensing.md) | **日本語** | [한국어](../ko/licensing.md)

このページでは、SunPack リポジトリのライセンスの適用範囲と、配布時に保持する資料を説明します。要約と原文に違いがある場合は原文が優先されます。

## SunPack 独自コード

SunPack 用に作成したソースコードは、ルートの [MIT ライセンス](../../LICENSE) に従います。同梱するサードパーティーコードには、各上流プロジェクトと [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md) に記載された元のライセンスが適用されます。

## 同梱の 7-Zip 26.05

必要な部分を選んでローカル変更を加えた 7-Zip 26.05 ソースを、従来のパス `sunpack/sevenzip_bridge/7z2604-src/` に置いています。このツリーには上流の 7-Zip ソースライセンスが適用されます。原文は [ソースツリーの License.txt](../../sunpack/sevenzip_bridge/7z2604-src/DOC/License.txt)、配布用の複製は [licenses/7zip-source-license.txt](../../licenses/7zip-source-license.txt) にあります。

| ファイル | 適用条件 |
| --- | --- |
| `CPP/7zip/Compress/Rar*` | GNU LGPL と unRAR ライセンスの制限 |
| `CPP/7zip/Compress/LzfseDecoder.cpp` | BSD 3-Clause |
| `C/ZstdDec.c` | BSD 3-Clause |
| `C/Xxh64.c` | BSD 2-Clause |
| パブリックドメインと明記されたファイル | その扱いを保持 |
| その他の 7-Zip ソース | GNU LGPL 2.1 以降 |

[GNU LGPL 2.1 の全文](../../licenses/LGPL-2.1.txt) も収録しています。LGPL 対象ファイルを変更した場合は、上流の著作権・ライセンス表示を残し、変更した旨と変更日を記載します。unRAR の制限が付く展開ソースには、独自の RAR 圧縮アルゴリズムの再作成に利用できないという上流の制限を残します。詳細は上流のライセンス原文を参照してください。

SunPack 固有の統合コードは可能な限り `7z2604-src/` の外側に置きます。上流由来の範囲を追跡しやすくし、バージョン更新時の統合作業を減らせます。

## 同梱の zlib-ng 2.3.3 と開発ツール

ZIP Deflate の高速処理で使用するソースは `sunpack/sevenzip_bridge/zlib-ng-2.3.3/` にあります。上流コミット `12731092979c6d07f42da27da673a9f6c7b13586` に固定し、上流 zlib ライセンスに従います。ソース・バイナリの再配布時には上流の著作権と許諾表示を保持します。[ライセンスの複製](../../licenses/zlib-ng-license.txt) を参照してください。

開発セットアップが取得する `7z.exe`、`7z.dll`、`7zCon.sfx` はテストデータ生成用です。[7-Zip バイナリの配布条件](../../licenses/7zip-license.txt) が適用されます。

## リリースパッケージ

`scripts/generate_license_bundle.ps1` が生成する `THIRD_PARTY_LICENSES.txt` をインストールします。SunPack の MIT ライセンス、サードパーティーの概要、リポジトリの `licenses/`、GUI 依存ライブラリー（FreeType と stb を含む）の告知、および対象 Windows 向けロック済み Cargo 依存関係のライセンス・告知を収録します。ビルド・テスト用の告知が入る場合もあります。各ファイルの適用範囲は元の告知に従います。

原本はリポジトリと GUI 依存ソースに残ります。インストーラーはルートの MIT ライセンスを表示し、ライセンスのソースツリーは別途インストールしません。必須資料が欠けている場合は生成に失敗します。新しい依存関係を追加するときもライセンス条件を確認してください。

LGPL 対象の 7-Zip コードをコンパイルまたはリンクするリリースでは、ビルドに使った正確なソース、受領者による対象コードの変更、組み合わせた成果物の再ビルド・再リンクについて、適用される LGPL 条件を満たす必要があります。関連するソースやビルド資料を配布手順から取り除く前にライセンス上の確認を行ってください。

## 7-Zip 更新時

1. 上流のライセンスファイルをソースと同時に取り込みます。
2. 同じバージョンの原文で `licenses/7zip-source-license.txt` を更新します。
3. RAR、BSD、パブリックドメインの例外を含め、上流の条件変更を確認します。
4. パス・バージョン・条件が変わった場合はサードパーティー告知と本ページを更新します。
5. すべての必須ライセンスと帰属表示が統合ファイルに入ることをリリーステストで確認します。
